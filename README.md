## 📖 Overview

**M2K Signage** is an elegant, modern corporate landing page built for businesses in the outdoor advertising and architectural signage industry. Designed with attention to aesthetic detail, it showcases custom craftsmanship—ranging from 3D channel letters and LED neon signage to large-scale exterior installations.

The website delivers a fast, fluid user experience with pure semantic HTML5 and modular CSS3, complete with glassmorphic elements, smooth scroll transitions, and cross-device responsiveness.

🔗 **Live Deployment:** [https://m2ksignage.netlify.app](https://m2ksignage.netlify.app)

---

## ✨ Key Features

- **💎 Modern Visual Design:** Glassmorphism navigation bar with blur backdrop filter, subtle elevation shadows, and custom design tokens.
- **📱 Fully Responsive:** Adaptive layouts optimized for desktops, laptops, tablets, and smartphones using modern CSS Grid and Flexbox.
- **🧭 Smooth Navigation:** Fixed header with smooth page scrolling and scroll-padding offsets for effortless section hopping.
- **⭐ Services & Advantages:** Highlighted company core competencies (Established Company, Expert Designers, Professional Installation, Customer Satisfaction).
- **🎨 Custom Craftsmanship & Materials:** Dedicated sections outlining bespoke design capabilities and weather-resistant, premium build materials.
- **🖼️ Project Portfolio Gallery:** Responsive grid layout showcasing completed outdoor advertising and custom signage projects.
- **💡 Featured Products:** Highlighted sign categories including 3D Letter Signs, LED Neon Signs, and Open Face Channel Letter Signs.
- **💬 Client Testimonials:** Verified reviews with star ratings and client attributions.
- **📩 Contact Section:** Inquiry form and location imagery to drive customer engagement and lead generation.
- **⚡ Zero Dependency Overhead:** Pure Vanilla HTML & CSS ensuring lightning-fast load times and top performance scores.

## 🚀 Getting Started

To run this project locally on your machine:

### 1. Clone the repository

```bash
git clone https://github.com/kucukagtas/m2kSignage.git
```

### 2. Navigate to the project folder

```bash
cd m2kSignage
```

### 3. Open in your browser

- Simply double-click `index.html` to open it in your default web browser.
- **Or** use a local development server (such as VS Code's **Live Server** extension or `npx serve`):
  ```bash
  npx serve .
  ```
